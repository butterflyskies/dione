# Discord tool contracts

Descriptive catalogs and typed requests for nine metadata tools, six query tools, four message-management tools and reply. Existing schemas, parse order, concrete failure causes and legacy optional-field behavior are retained.

The embedding supplies evidence enablement and codec values from its current configuration snapshot. A parsed request, message identifier or hook name grants no access or execution authority. Root adapters keep resident registration, live config, policy gates, consent, verified targets, HTTP transport and state updates.

Reply text remains borrowed from the caller input. Strict cursors, response-version precedence, visibility limits and search field paths preserve their existing contracts. No registry, executor injection or transport factory is added.
