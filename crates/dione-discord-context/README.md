# dione-discord-context

Complete Discord implementation of Rook context reads and validated native metadata projection. A trusted embedding provides a fresh ordinary QueryCtx factory. The provider invokes it before network reads and again before disclosing results. Recipient authorization remains in the Rook service. No production registration is installed by this package.

Native metadata is descriptive and grants no delivery or sealed ingress authority. The root application retains conversion from its sealed live observation into retained records. The final policy denial preserves AccessDenied and displayed text while its nested typed cause is now the existing read-owner QueryError rather than the root MessagingError.
