# Discord operations

Owns complete authorized reply, DM, edit, reaction, attachment, thread and message-management operations and the shared Discord MCP service registrations. Preparation, target checks, per-chunk sent bookkeeping, consent settlement and coordination retain their existing ordering and cancellation semantics.

Applications provide the existing concrete HTTP, configuration, state, consent, ingress and notification resources. Tool registrations keep their actual policy and parse through the descriptive tool-contract owners. This owner does not construct gateway proofs or add permissions. The Rook publication provider remains implemented and fixture-covered without a production registration established by this move.

Default-off `test-support` exposes only read-only installed-pipeline metadata. Hook injection and gateway-event fixtures remain private unit-test code.
