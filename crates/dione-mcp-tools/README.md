# Dione MCP tools

Immutable tool registration and owner-provided execution contracts. Validated
names preserve exact spelling, reserved conflicts precede duplicates, and
ordered discovery uses the current presentation context. Handlers borrow their
arguments through Send futures and retain typed causes until protocol rendering.

The application supplies a fresh concrete reserved-name set at construction.
This crate has no harness or platform dependency and owns no transport origin,
readiness, native permission or reply authority. Registrations default to
seat-only access; resident access requires explicit opt-in. Representations stay
private and there is no unchecked name construction or deserialization.
