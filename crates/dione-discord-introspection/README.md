# Dione Discord introspection

Owns Discord metadata reads, permission evaluation, bounded audience observation and historical tool result projection. Root keeps resident admission, JSON argument parsing and call-entry configuration selection. Contexts accept the existing shared SDK client and configuration snapshot; their fields and permission preparation stay private.

Audience results are non-atomic observations, never disclosure grants. Unknown lookups remain distinct from permission denial. Existing user limits, page/member caps, deadline, response order, private-thread reads and literal wire results are preserved.

Private tests drive the SDK through loopback HTTP and exercise permission precedence, missing data, partial pages and deadline behavior. They do not establish live authenticated Discord access. Installed tool registration and resident-policy tests remain at root.
