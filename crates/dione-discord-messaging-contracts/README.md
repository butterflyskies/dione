# dione-discord-messaging-contracts

Complete descriptive messaging outcomes, target failures, notification flags and MCP JSON projection. Metadata constructors do not perform publication, validate ingress, settle consent or grant target authority. Root retains all network, ledger, verification, consent, coordinator and provider execution. ChannelRef is the existing numeric metadata wrapper, with unchanged constructor/get/Display behavior.

Unknown delivery remains nonretryable with only its confirmed prefix. Wire output preserves hold liveness, rewrites, evidence roles, partial order and DM route distinctions. Receipt fields remain private and are exposed through metadata construction and borrowing accessors only.
